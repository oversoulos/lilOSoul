
## Default Features

| Feature | What it does |
|---------|--------------|
| System Monitoring | Shows CPU, RAM, processes in panel |
| VPN Status | Shows VPN connection status |
| Dynamic Theming | Auto-colors from wallpaper |
| Audio Wavelength | Audio spectrum visualizer |
| Calendar Events | Shows upcoming events from khal |
| Clipboard Paste | Paste from history with Shift+Return |

## Custom Dashboards

| Dashboard | Purpose | Toggle |
|-----------|---------|--------|
| SolCmd | Main dashboard with AI, crypto, system control | `dashboards.solcmd.enable` |
| System Monitor | Floating resource monitor | `dashboards.systemmonitor.enable` |
| AI Assistant | Chat interface | `dashboards.ai-assistant.enable` |

## Hotkeys (if configured)

| Key | Action |
|-----|--------|
| `SUPER + Ctrl + Space` | Open AI dashboard |
| `Shift + Return` | Paste from clipboard history |
