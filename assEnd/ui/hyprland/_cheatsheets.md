
## Default Keybinds

| Key | Action |
|-----|--------|
| `SUPER + Return` | Launch Ghostty terminal |
| `SUPER + Q` | Close active window |
| `SUPER + E` | Open Yazi file manager |
| `SUPER + R` | Open Wofi launcher |
| `SUPER + C` | Open Hyprland live config |
| `SUPER + M` | Exit Hyprland |
| `SUPER + V` | Toggle floating |
| `SUPER + F` | Toggle fullscreen |
| `SUPER + Space` | Omni-search (apps, notes, files) |
| `SUPER + ~` | Quake dropdown terminal |
| `SUPER + D` | System monitor drawer |
| `SUPER + Y` | Clipboard manager |
| `SUPER + .` | Emoji picker |
| `SUPER + W` | Wallpaper gallery |
| `F5` | Start voice dictation |
| `SHIFT + F5` | End voice dictation |

## Window Management

| Action | Command |
|--------|---------|
| Move focus | `movefocus, l/r/u/d` |
| Move window | `movewindow, l/r/u/d` |
| Resize window | `resizeactive, dx dy` |
| Toggle floating | `togglefloating` |
| Toggle fullscreen | `fullscreen` |
| Change workspace | `workspace, n` |
| Move to workspace | `movetoworkspace, n` |

## Plugins Quick Reference

| Plugin | Purpose | Keybind (if any) |
|--------|---------|------------------|
| hy3 | i3-like tiling | `SUPER + H` etc. |
| hyprspace | Workspace overview | `SUPER + Tab` |
| hyprsplit | dwm-like workspaces | Configurable |
| hyprgrass | Touch gestures | Touchpad gestures |
| hypr-dynamic-cursors | Cursor physics | Auto |
